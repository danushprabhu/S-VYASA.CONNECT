# CampusConnect – S-VYASA Campus

CampusConnect is a front-end web prototype designed to improve student engagement and campus communication. It provides students, faculty, parents, and admins with a simple interactive campus dashboard.

## Features

* 📅 Campus events and announcements
* 🏫 Classroom and room availability
* 👨‍🏫 Faculty selection and doubt chat
* 🤖 “Bees” campus assistant
* 🎯 Hackathon updates
* 👥 Role-based Student, Faculty, Parent and Admin views
* 📱 Responsive and interactive interface
* 🎤 Voice interaction using Web Speech API

## Technologies

HTML5 • CSS3 • JavaScript • Web Speech API • Google Fonts

## Run

Open `index.html` directly in a browser or use VS Code Live Server.

## Note

This is a demo/prototype using static data. It does not currently include a backend, database, or real authentication.

## Future Scope

Add a backend, database, real-time notifications, secure authentication, and live campus data.
